# Data

This directory is intended to store input data required for the analysis pipeline.

## Data Availability

Raw participant data are not included in this repository in order to comply with ethical guidelines and protect participant privacy.

## Expected Data Types

The analysis pipeline is designed to work with the following data:

- Behavioral data exported from the BART task (e.g., `.csv`, `.xlsx`)
- EEG recordings (e.g., `.xdf` format)
- Processed or merged datasets generated during preprocessing
